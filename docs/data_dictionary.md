# Data Dictionary — Gold Layer

Documentation of all columns in the Gold analytical tables.
All tables are stored as Delta tables in the `nyc_taxi.gold` schema.

## gold_hourly_demand

Trips and revenue aggregated by pickup zone and hour of day.

| Column | Type | Description |
|--------|------|-------------|
| pickup_borough | string | NYC borough where the trip started |
| pickup_zone | string | TLC taxi zone where the trip started |
| hour_of_day | int | Hour the trip started (0 to 23) |
| total_trips | long | Number of trips in that zone and hour |
| total_revenue | double | Total revenue generated (sum of total_amount) |
| avg_ticket | double | Average fare per trip |
| avg_distance | double | Average trip distance in miles |

## gold_borough_revenue

Revenue and trips aggregated by pickup borough and month.

| Column | Type | Description |
|--------|------|-------------|
| pickup_borough | string | NYC borough where the trip started |
| trip_month | int | Month of the trip (1 to 12) |
| total_trips | long | Number of trips in that borough and month |
| total_revenue | double | Total revenue generated |
| avg_ticket | double | Average fare per trip |
| total_tips | double | Total tips collected |

## gold_shift_metrics

Operational metrics aggregated by time-of-day shift.

| Column | Type | Description |
|--------|------|-------------|
| shift_period | string | Time-of-day shift: Overnight (0-6h), Morning (6-12h), Afternoon (12-18h), Evening (18-24h) |
| total_trips | long | Number of trips in that shift |
| total_revenue | double | Total revenue generated |
| avg_ticket | double | Average fare per trip |
| avg_distance | double | Average trip distance in miles |
| avg_duration_min | double | Average trip duration in minutes |
| revenue_per_trip | double | Revenue efficiency (total revenue divided by trip count) |

## gold_zone_ranking

Pickup zones ranked by revenue, using window functions.

| Column | Type | Description |
|--------|------|-------------|
| pickup_borough | string | NYC borough where the trip started |
| pickup_zone | string | TLC taxi zone where the trip started |
| total_trips | long | Number of trips originating in the zone |
| total_revenue | double | Total revenue generated by the zone |
| revenue_rank_overall | int | Zone rank by revenue across all zones (1 = highest) |
| revenue_rank_in_borough | int | Zone rank by revenue within its own borough |
| revenue_share_pct | double | Zone's share of total revenue, as a percentage |

## gold_monthly_cohort

Monthly demand trend with month-over-month variation, using the LAG window function.

| Column | Type | Description |
|--------|------|-------------|
| trip_month | int | Month of the trip (1 to 12) |
| total_trips | long | Number of trips in the month |
| total_revenue | double | Total revenue generated in the month |
| avg_ticket | double | Average fare per trip |
| prev_month_revenue | double | Revenue of the previous month (null for January) |
| revenue_mom_pct | double | Month-over-month revenue growth, as a percentage |
